Under The Hood
How It Actually Works
🧩
Authenticated Chrome Extension
Manifest V3, sideloaded for hackathon — Web Store-ready for production. NextAuth session cookie rides cross-origin via host_permissions + credentials: 'include'. Works on any grant site, no per-platform integration needed.
✅
NPO Hub API · Tier 3 Verified Org Profile
NPO Hub API exchanges the session for a Bongentic JWT scoped to the user's org. Live org profile + programs data — nothing stored locally, every fetch scoped to the org's verified identity.
⚡
Form Field Filler Tool · Que Skill
Reads scraped form-field metadata (label, name, type) + org profile + programs. Returns structured field suggestions — direct invocation, no agent loop. Fast and deterministic.
💾
Grant Opportunity Extractor Tool · Que Skill
Fetches the public grant page, extracts a structured grant record (title, deadlines, amount ranges, eligibility), and writes it directly to NPO Hub Grants Management.
